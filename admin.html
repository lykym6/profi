Вход

Пароля здесь нет: сайт лежит на GitHub, поэтому вход делается «ключом» (токеном). Он создаётся один раз.

  1. Откройте создание токена на GitHub (нужно быть залогиненным в свой аккаунт).
  2. Название любое, срок «No expiration» или год. В «Repository access» выберите «Only select repositories» и ваш репозиторий сайта.
  3. В «Permissions → Repository permissions» найдите Contents и поставьте Read and write. Нажмите «Generate token» и скопируйте длинный код (он показывается один раз).
  4. Вставьте код в поле ниже, поставьте галочку «Запомнить» и нажмите «Войти».
